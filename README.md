# 💻 Web Applications

## HTML CSS and Javascript

A personal presentation website built entirely from scratch using foundational front-end web technologies. This project was developed as part of a web development workshop aimed at mastering essential tools for web creation, layout design, and dynamic script implementation.

---

### Project Overview

This webpage serves as an interactive personal portfolio and presentation platform. It displays personal background, academic coursework, weekly class schedules, personal hobbies, a photo gallery, and an interactive contact form.

#### **Features**
* **About Me & Hobbies:** Personal introduction and interests.
* **Academic Schedule:** Details on current coursework and weekly timetable.
* **Photo Gallery:** A visual layout featuring selected images.
* **Contact Form:** Interactive user input form for direct messaging.

---

### Built With

* **[HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML):** Defines the structural skeleton, semantic content, and markup of the web pages.
* **[CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS):** Handles styling, visual layout, responsive formatting, and element positioning (classes, IDs, tags).
* **[JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript):** Implements dynamic interactive features and logic inside `script.js`.
* **[jQuery](https://jquery.com/):** JavaScript library utilized to simplify DOM manipulation, event handling, and animation effects.

---

### Key Learnings & Challenges

Developing this site provided hands-on experience with front-end workflows, along with specific technical problem-solving insights:

1. **Design & Styling Strategy:** Conceptualizing an intuitive and visually pleasing design layout from scratch required multiple styling iterations.
2. **CSS Element Architecture:** Managing and referencing complex cascading rules across various HTML tags, class attributes, and unique IDs required structured organization.
3. **JavaScript Logic (`script.js`):** Overcoming the initial learning curve associated with DOM manipulation, event listeners, and script execution flow without prior extensive experience.

### Getting Started

To view or run this project locally, simply clone the repository and open the index file in any web browser.

```bash
# Clone the repository
git clone [https://github.com/your-username/personal-presentation-webpage.git](https://github.com/your-username/personal-presentation-webpage.git)

# Navigate to the project directory
cd personal-presentation-webpage

# Open index.html in your default web browser
# On macOS:
open index.html

# On Windows:
start index.html

# On Linux:
xdg-open index.html
